## Overview

Defect In Comment Diff was a personal tool to analyze some body comments for prefixed-base Ids. 
It was developed and maintained during my first job, for that job. And it also help me in the later job.

I've used to work with a team where manual data processing and analysing take away most of my time. There were multiple tracking system for bugs, 
and all of them have Id for each item, which the team called `Defect`. 
In the end of the day, I need to report the changes in bug status comparing with yesterday one, and also read the other comments for aggregation and ... 
most of my friends using spreadsheet for counting thems. I use this for myself first and share it away in the project.

## What and how it worked

Simple, just text analysing. And now, 2025, AI can help you explain all of the code there.
